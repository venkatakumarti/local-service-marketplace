# 🧑‍🔧 Local Service Marketplace

## 📌 Objective
A web application that connects users with local service providers such as electricians, plumbers, and technicians.

## 🛠 Tech Stack
- PostgreSQL
- Express.js
- React.js
- Node.js

## 🚀 Features
- User registration and login
- Service provider registration
- Search for services (plumber, electrician, etc.)
- Book services
- Manage bookings

## 📊 Status
🚧 In Progress – Backend and database design in progress

## 💡 Future Enhancements
- Ratings and reviews
- Availability scheduling
- Real-time booking updates
